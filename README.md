# Foodtruck Finder

Foodtrucks live auf der Karte finden — mit Standort, Status (LIVE / Jetzt hier / Kommt bald / Wochenplatz) und Google-Maps-Navigation. Foodtruck-Betreiber melden sich mit ihrem Partyretter-Konto an und setzen ihren Live-Standort mit einem Knopf.

Ein Service von [Partyretter](https://partyretter.com) — Foodtrucks, Privatköche, Getränke & Events buchen.

Statische PWA (Leaflet + MapTiler, Daten live von der Partyretter-API). Gehostet über GitHub Pages.
